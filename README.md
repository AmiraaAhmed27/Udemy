## Overview
This Power BI dashboard provides an analytical overview of Udemy courses data, helping uncover insights about subscriptions, revenue, pricing, course levels, and course performance across different subjects.

The dashboard is designed to support data-driven decisions by analyzing trends and user engagement across the platform.

---

##  Key Insights

- Total Courses: **3,672**
- Total Subscribers: **12M**
- Total Revenue: **882M**
- Total Reviews: **574K**
- Average Course Price: **66.10**

### Subject Analysis
- Web Development dominates both subscribers and revenue.
- Business Finance and Graphic Design follow as the next strongest categories.

### Course Level Insights
- “All Levels” courses attract the highest number of subscribers.
- Beginner-level courses also contribute significantly to engagement.

### Revenue Analysis
- Revenue peaked around 2015–2016.
- Top-performing courses generated over **24M** in revenue.

### 🆓 Paid vs Free Courses
- Paid courses represent the majority of subscriptions and revenue generation.
